Testers must be provided credentials across 7 distinct security tiers to evaluate RBAC and multi-tenant isolation:
- **Tier 0:** Anonymous Guest (Unauthenticated boundary & rate-limiting validation)
- **Tier 1:** Standard User A (Personal library CRUD, bookmarks, reading progress)

- **Tier 3:** Scholar Reviewer (`scholar_reviewer` role; workflow validation)
- **Tier 4:** Content Admin (`content_admin` role; CMS publishing boundaries)
- **Tier 5:** Platform Admin (`admin` role; user management & feature flags)
- **Tier 6:** Super Admin (`super_admin` role; root platform administration & self-protection triggers)

### 3.3 Permitted vs. Prohibited Testing
- **PERMITTED:** Parameter tampering, BOLA/IDOR, XSS injection, SQL injection attempts, rate-limit threshold validation, CSRF/CORS review, JWT tampering, privilege escalation attempts.
- **PROHIBITED:** Volumetric DDoS (network flooding), modification or defacement of canonical scripture text, destructive database drops, social engineering/phishing, physical attacks, attacks on production systems.

### 3.4 Mandatory Identification & Escalation
