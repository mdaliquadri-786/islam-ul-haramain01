### Security Notice
> [!CAUTION]
> - Never commit `key.properties`, `*.jks`, or `*.keystore` into git version control. They are protected in `.gitignore`.
> - Never share your keystore passwords in chat, prompt logs, or public repositories.
> - Safely back up your release keystore `upload-keystore.jks` in a secure password manager or offline cold storage. If lost, Google Play will not allow you to update the app!

### Step 1: Install Required Build Prerequisites

#### A. Install JDK 17 (Java Development Kit)
Modern Android Gradle Plugin 8+ and Flutter require OpenJDK 17:
- Download and install Microsoft Build of OpenJDK 17 or Eclipse Temurin 17:
  ```powershell
  winget install Microsoft.OpenJDK.17
  ```
- Verify:
  ```powershell
  java -version
  keytool -help
  ```

#### B. Install Android Studio & Android SDK
- Download Android Studio from [https://developer.android.com/studio](https://developer.android.com/studio) or install via winget:
  ```powershell
  winget install Google.AndroidStudio
  ```
- Launch Android Studio and install:
  - **Android SDK Platform-Tools** (v34 or v35)
  - **Android SDK Build-Tools 34.0.0**
  - **Android SDK Command-line Tools (latest)**
- Set Environment Variables:
  ```powershell
  [System.Environment]::SetEnvironmentVariable("ANDROID_HOME", "$env:LOCALAPPDATA\Android\Sdk", "User")
  ```

#### C. Configure Flutter with Android SDK
- Open a command prompt with Developer Mode enabled or run as administrator once if Puro needs symlink permissions:
  ```powershell
  flutter config --android-sdk "$env:LOCALAPPDATA\Android\Sdk"
  flutter doctor --android-licenses
  flutter doctor -v
  ```

### Step 2: Generate Release Keystore
In the root of the mobile application directory (`apps/mobile`):
```powershell
keytool -genkey -v -keystore upload-keystore.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
```
When prompted:
- Enter a strong keystore password and store it safely in your password manager.
- Fill in developer organizational details (e.g. First/Last Name, Org: `Islam Ul Haramain`).

---

### Step 3: Configure `key.properties`
Create file `apps/mobile/android/key.properties` (based on `key.properties.example`):
```properties
keyAlias=upload
keyPassword=YOUR_ACTUAL_KEY_PASSWORD
storeFile=../../upload-keystore.jks
storePassword=YOUR_ACTUAL_KEYSTORE_PASSWORD
```
*(Replace `YOUR_ACTUAL_KEY_PASSWORD` and `YOUR_ACTUAL_KEYSTORE_PASSWORD` with the passwords chosen in Step 2).*

---

### Step 4: Build Production Android App Bundle (.aab)
Run the release build command pointing compile-time definitions strictly to the **production** Supabase project:

```powershell
cd apps/mobile
flutter build appbundle --release --no-pub `
  --dart-define=SUPABASE_URL=https://qovdthhbtqegqjyolcfe.supabase.co `
  --dart-define=SUPABASE_ANON_KEY=YOUR_PRODUCTION_ANON_KEY
```

---

### Step 5: Verify Artifact Output
Confirm output file exists and is non-empty:
```text
apps/mobile/build/app/outputs/bundle/release/app-release.aab
```
- Verify expected file size (typically ~25MB - 45MB).
- Verify bundle contains only production configuration and zero staging references (`mlxyegiwdzmcybvhtgwy`).

---

### Step 6: Backup Keystore
- Immediately copy `upload-keystore.jks` and its alias/passwords to an encrypted external backup.
- Without this keystore, future app updates cannot be published to Google Play.
