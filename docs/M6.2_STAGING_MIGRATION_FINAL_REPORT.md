### 3. Forensic Review of Migration 12 Repair

- **Original Failure:** Migration 12 failed during the initial application pass with `ERROR: function public.is_platform_admin(uuid) does not exist (SQLSTATE 42883)`.
- **Root Cause:** Forward-reference sequencing defect. RLS policies in M12, M13, and M14 referenced `public.is_platform_admin(auth.uid())`, but the function was initially defined in Migration 17, which delegated to `public.is_admin()` defined in Migration 15.
- **Repair Executed:** Forward-declared canonical, idempotent implementations of `public.is_admin(lookup_uid UUID DEFAULT auth.uid())` and `public.is_platform_admin(lookup_uid UUID DEFAULT auth.uid())` directly in Migration 12 before Section 5.3 Administrative Policies.
- **Dependency Safety:** `is_admin` depends exclusively on `public.user_roles`, which was created in Migration 01. Thus, at the start of Migration 12, all dependencies were already satisfied.
- **Idempotency Validated:** When Migration 15 and Migration 17 executed on remote staging, their `CREATE OR REPLACE FUNCTION` statements executed cleanly and seamlessly, leaving authoritative security definitions in place without errors or warnings.
