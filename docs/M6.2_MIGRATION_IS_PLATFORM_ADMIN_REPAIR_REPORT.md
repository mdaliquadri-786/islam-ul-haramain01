### 3. Forensic Root Cause Analysis

1. **Failure Trigger:**
   In Migration 12 (`20260924000003_audio_streaming_reciters.sql`), statements 10 and 11 declared administrative RLS policies:
   ```sql
   CREATE POLICY "Admins can manage audio reciters"
   ON public.audio_reciters FOR ALL
   TO authenticated
   USING (public.is_platform_admin(auth.uid()))
   WITH CHECK (public.is_platform_admin(auth.uid()));
   ```
2. **Missing Function:**
   At migration time for M12, `public.is_platform_admin(uuid)` did not exist in the database catalog.
3. **Sequencing Dependency Flaw:**
   - `is_platform_admin` was originally created in Migration 17 (`20261001000000_m9_rls_hardening.sql`, lines 19–32).
   - In Migration 17, `is_platform_admin` delegates to `public.is_admin(lookup_uid)`.
   - `public.is_admin` was defined in Migration 15 (`20260925000001_admin_system_rbac_config_subscriptions.sql`, lines 97–117).
   - `public.is_admin` depends exclusively on `public.user_roles`, which was created in Migration 01 (`20260922000001_core_schema_auth_rls.sql`).
   - Furthermore, Migrations 13 (`tafsir_comparative_viewer.sql`) and 14 (`digital_islamic_books_ereader.sql`) also use `public.is_platform_admin(auth.uid())`.
4. **Resolution Strategy:**
   Because Migration 12 was the earliest unapplied migration and the first to require `is_platform_admin`, forward-declaring canonical definitions of `is_admin` and `is_platform_admin` directly inside Migration 12 resolves the dependency for M12, M13, and M14. When M15 and M17 execute later, their `CREATE OR REPLACE FUNCTION` statements execute idempotently without conflict.

### 4. Minimal Code Modification Applied

File modified: `supabase/migrations/20260924000003_audio_streaming_reciters.sql`  
Lines added: 97–140 (immediately preceding Section 5.3 Administrative Policies):

```sql
-- ----------------------------------------------------------------------------
-- Prerequisite Administrative Check Functions (Forward-declared for RLS)
-- Canonical definitions from 20260925000001 (M15) and 20261001000000 (M17)
-- ----------------------------------------------------------------------------
CREATE OR REPLACE FUNCTION public.is_admin(lookup_uid UUID DEFAULT auth.uid())
RETURNS BOOLEAN AS $$
BEGIN
    IF lookup_uid IS NULL THEN
        RETURN FALSE;
    END IF;

    RETURN EXISTS (
        SELECT 1 FROM public.user_roles
        WHERE user_id = lookup_uid
        AND role IN (
            'super_admin',
            'admin',
            'content_admin',
            'scholar_reviewer',
            'support_admin',
            'billing_admin'
        )
    );
END;
$$ LANGUAGE plpgsql SECURITY DEFINER SET search_path = public, pg_temp;

REVOKE EXECUTE ON FUNCTION public.is_admin(UUID) FROM PUBLIC;
GRANT EXECUTE ON FUNCTION public.is_admin(UUID) TO authenticated, anon;

CREATE OR REPLACE FUNCTION public.is_platform_admin(lookup_uid UUID DEFAULT auth.uid())
RETURNS BOOLEAN AS $$
BEGIN
    IF lookup_uid IS NULL THEN
        RETURN FALSE;
    END IF;

    -- Delegates to canonical is_admin check defined in 20260925000001
    RETURN public.is_admin(lookup_uid);
END;
$$ LANGUAGE plpgsql SECURITY DEFINER SET search_path = public, pg_temp;

REVOKE EXECUTE ON FUNCTION public.is_platform_admin(UUID) FROM PUBLIC;
GRANT EXECUTE ON FUNCTION public.is_platform_admin(UUID) TO authenticated, anon;
```
