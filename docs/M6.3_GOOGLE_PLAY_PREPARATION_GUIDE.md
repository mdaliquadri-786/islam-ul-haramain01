### 4. Build & Signing Instructions (Android Release)

#### Step 1: Install Android SDK (if not already installed)
Install Android Studio or Command-Line Tools, then inform Flutter of its location:
```bash
flutter config --android-sdk "C:\path\to\android-sdk"
```

#### Step 2: Generate Release Keystore
In PowerShell / Terminal:
```bash
keytool -genkey -v -keystore apps/mobile/upload-keystore.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
```

#### Step 3: Configure `key.properties`
Create `apps/mobile/android/key.properties`:
```properties
keyAlias=upload
keyPassword=<KEY_PASSWORD>
storeFile=../../upload-keystore.jks
storePassword=<KEYSTORE_PASSWORD>
```

#### Step 4: Build Production AppBundle (AAB)
```bash
flutter build appbundle --release --no-pub \
  --dart-define=SUPABASE_URL=https://<PROD_PROJECT_REF>.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=<PROD_ANON_KEY>
```
Output: `apps/mobile/build/app/outputs/bundle/release/app-release.aab`
