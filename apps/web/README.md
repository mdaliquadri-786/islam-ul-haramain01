# @islamic/web

**Directory:** `apps/web`  
**Framework:** Next.js 15 (App Router), React 19, TypeScript  
**Status:** Milestone 1.1 Foundation Skeleton  

## Scope & Boundaries
* Houses the Next.js 15 application.
* References internal workspace packages:
  * `@islamic/islamic-engine`
  * `@islamic/database`
  * `@islamic/ui`
* Product features (Quran reader, Hadith navigator, Prayer widgets) will be incrementally built in Phases 2–4.
