## 2. WEB DEPLOYMENT SPECIFICATION & PROCEDURES

### 2.1 Artifact Characteristics
- **Engine:** Next.js 14 with App Router.
- **Compiled Routes:** 603 of 603 static and dynamic routes.
- **Output Mode:** Standalone server output (`output: 'standalone'`) configured in `apps/web/next.config.mjs`.
- **Static Assets:** Exported to `.next/static` with immutable cache headers (`Cache-Control: public, max-age=31536000, immutable`).

### 2.2 Environment Configurations
Required production environment variables:
```bash
NEXT_PUBLIC_APP_URL=https://islamic-platform.org
NEXT_PUBLIC_SUPABASE_URL=https://<prod-project-ref>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<prod-anon-key>
SUPABASE_SERVICE_ROLE_KEY=<prod-service-role-key-secret>
ADMIN_JWT_SECRET=<prod-jwt-secret>
```

### 2.3 Deployment Commands
- **Option A (Vercel CLI / Git Integration):**
  ```bash
  vercel deploy --prod --cwd apps/web
  ```
- **Option B (Docker Containerized Deployment):**
  ```bash
  docker build -f apps/web/Dockerfile -t haramain/web:v1.0.0 .
  docker run -d -p 3000:3000 --env-file .env.production haramain/web:v1.0.0
  ```

## 4. ANDROID RELEASE PIPELINE (GOOGLE PLAY STORE)

### 4.1 Release Build Specification
- **Format:** Android App Bundle (`.aab`).
- **Target SDK:** 34 (Android 14).
- **Min SDK:** 24 (Android 7.0 Nougat).
- **Architecture:** `arm64-v8a`, `armeabi-v7a`, `x86_64`.
- **Permissions:** `INTERNET`, `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK`, `WAKE_LOCK`.

### 4.2 Automated CI Build Command
On a Linux CI runner with Android SDK configured:
```bash
flutter build appbundle --release --flavor production
```

### 4.3 Google Play Console Internal Track Deployment
1. Upload generated bundle: `build/app/outputs/bundle/productionRelease/app-production-release.aab`.
2. Release track progression: **Internal Testing** -> **Closed Alpha (Scholar Board)** -> **Open Beta** -> **Production**.
3. **Data Safety Declaration on Play Console:**
   - Location: Not collected / Not stored (calculated strictly on-device).
   - Personal Info: Optional email for authenticated sync only.
   - Financial Info: None.
   - Health Info: None.
   - Device or other IDs: Not collected.
   - Advertising ID: Not used.
   - Data encryption in transit: Yes (TLS 1.3).
   - Data deletion request: Enabled via user profile settings.
