## 2. Original Root Cause

During execution of `supabase db push --linked`, Migration 07 (`20260923000003_hadith_collections_engine.sql`) failed at statement 30 with:
```text
ERROR: type "app_role" does not exist (SQLSTATE 42704)
```

**Root Cause:** The database schema models roles as `VARCHAR(30)` in `public.user_roles` with a `CHECK` constraint. The helper function `public.has_any_role` expects `check_roles VARCHAR[]`. No PostgreSQL `ENUM` or composite type named `app_role` exists in the schema or migrations. The explicit cast `ARRAY['super_admin'::app_role]` was an authoring anomaly present in Migrations 07 and 08. All other migrations in the repository pass standard string arrays (e.g. `ARRAY['super_admin']`).
