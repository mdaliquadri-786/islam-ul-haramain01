# Supabase Infrastructure Directory

**Directory:** `supabase`  
**Status:** Milestone 1.1 Structural Boundary  

## Structure
* `migrations/`: Version-controlled SQL migration files containing schema definitions, constraints, indexes, and Row Level Security (RLS) policies. Migration files will be authored starting in Milestone 1.2.
* `functions/`: Edge Functions (Deno/TypeScript) for compute tasks.
