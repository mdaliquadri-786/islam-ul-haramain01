# @islamic/islamic-engine

**Status:** Milestone 1.1 Boundary Skeleton  
**Purpose:** Platform-agnostic TypeScript computational engine for deterministic Islamic calculations.

## Scope & Boundaries
* **Includes:**
  * Spherical trigonometric Qibla direction & distance formulas.
  * Deterministic astronomical solar position formulas for prayer times.
  * Astronomical algorithms for Umm al-Qura Hijri calendar conversions.
  * Arabic text diacritic stripping, normalizers, and search tokenizers.
* **Explicitly Excludes:**
  * No external REST API dependencies.
  * No direct database connections or user state management.
  * No theological extrapolations or synthetic religious content.

*Concrete calculations will be implemented in Milestone 3.1.*
