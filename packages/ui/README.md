# @islamic/ui

**Status:** Milestone 1.1 Boundary Skeleton  
**Purpose:** Shared design tokens, Islamic geometric styling variables, color palettes, and typographic scales.

## Scope & Boundaries
* **Includes:**
  * Color tokens (Emerald, Gold, Parchment, Sepia Mushaf palette).
  * Font family definitions for Arabic Uthmani, Urdu Nastaliq, and Latin UI.
  * Typographic scaling for Quranic verse rendering.
* **Explicitly Excludes:**
  * No complex UI widgets or application views yet (deferred to Phase 3/4).
